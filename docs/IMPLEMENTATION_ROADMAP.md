# 从学习项目到个人日常助手

当前已经验证真实 Gmail 单封邮件闭环；这里记录我的下一阶段计划，不表示这些能力已经完成或部署。

1. 限制范围：只处理主动添加 MailFlow 标签的邮件，发送和创建会议仍需审核。
2. 可靠获取：分页与数量上限；以账号和 Gmail message ID 记录状态，不删除旧运行，防止周期拉取重复提交。
3. 真实副作用：发送或建会超时先核验结果，再决定重试，避免重复执行。
4. 修复工具：统一日历时区、正确传递邀请通知参数；原邮件不存在时明确失败；真实运行中不以模拟成功掩盖 API 故障。
5. 配置与记忆：真实背景、签名和工作时间；账号隔离、规则冲突处理和时间边界校验。
6. 持久化：保存线程、偏好和处理记录，验证暂停审核、重启、找回原任务、恢复的完整过程。正式 Agent Server 由部署运行时管理存储，不用 Notebook 内存对象代替。
7. 小范围常驻：去重与失败恢复完成后再加周期拉取、运行限制和异常提示，当前 cron 入口不会自动补齐这些能力。
8. 长期部署：需要电脑关机后继续工作时，再选择托管或常驻服务器，配置认证、HTTPS、凭据管理和备份。

验收重点：同一封邮件不重复提交，未批准不发送，重启不丢任务，失败能被发现，工具成功能在真实邮箱或日历核实。
